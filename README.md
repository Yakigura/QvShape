QvShape は、VRChat 向けペン描画システム **QvPen** に、直線・矩形・三角形・塗りつぶし・円・チューブ・球体・点線といった幾何学図形の描画機能と、頂点／角度スナップ、消しゴムの削除予告ハイライト、鏡文字（対面反転）機能を追加する拡張システムです。

**QvPen 本体のスクリプト・プレハブを一切改変しない完全非破壊設計**のため、既存のワールドにワンクリックで導入でき、不要になれば削除するだけで元の状態に戻ります。QvPen 本体がアップデートされても壊れません。

## 主な機能

### 図形の描画

| モード | 内容 |
|---|---|
| **直線** | 通常直線 / ジグザグ線 / 波線（サイン波） |
| **矩形・三角形** | 四角形 / 直角三角形① / 直角三角形②（反転）/ 二等辺三角形 |
| **塗りつぶし** | 上記4形状の塗りつぶし（走査方向を水平／垂直で切替可能） |
| **円・弧** | 全円 / 半弧×2 / 1/4弧×4 |
| **円塗りつぶし** | 走査線（水平・垂直）/ 同心円 / 重ね塗りリング。全円・半円・扇形に対応 |
| **チューブ** | 螺旋 / 直線ラティス / 重ね塗りリング |
| **球体** | 水平螺旋 / 垂直螺旋 / 重ね塗りリング（水平・垂直）。全球および上下左右の半球 |
| **点線・破線** | 標準破線 / 細かい点線 / 長破線。直線・矩形・円に適用可能 |

「重ね塗りリング」スタイルで描いた図形は、リング1本ずつが独立したインクになるため、**描画後に消しゴムで一部だけを消せます。**

### 鏡文字（対面反転）

自分が手書きした文字や図形を、ショートカット操作ひとつで**対面の相手に向けて左右反転**させます。

- **主軸の自動検出**: 文字列が並んでいる方向を数学的に自動算出するため、斜めや真横から見ていても、その場で自然に裏返ります
- **壁面への自動スナップ**: 黒板や壁に描いた文字は、完全に平行な平面内で反転します
- **完全可逆**: 何度トグルしても歪みなく元の形に戻ります
- **巻き込み防止**: 直近に自分が描いたインクのみが対象です。他人の文字や過去のメモは反転しません

### 精密スナップ

- **頂点スナップ**: 既存のインクの端点に自動で吸着します
- **角度スナップ**: 15度刻みで角度を固定します（刻み幅は変更可能）

### 消しゴムの削除予告ハイライト

消しゴムを近づけると、これから消える対象のストロークが赤く発光して予告表示されます。「消したくない線まで消してしまった」を防ぎます。

### 操作 UI

- **ペン追従メニュー**: ペンを持っている間、手元に呼び出せるモード切替メニュー
- **据え置き UI パネル**: ワールドに固定設置されるモード切替パネル
- ペン先で直接タッチして押す操作、VR コントローラーのレーザー／Poke、デスクトップのキーボード操作に対応

### 安全機能（Anti-Griefing）

パブリックワールドやイベントでの悪用を防ぐ機能を標準搭載しています。

- **最大描画サイズ制限**: 部屋全体を覆うような巨大図形の生成をブロック
- **他プレイヤー頭部保護**: 他人の視界を覆う位置への描画を自動検知してブロック
- **連打スパム防止**: マクロ等による過剰なネットワーク送信をクールダウンで抑制
- **マスター限定モード**: インスタンスマスターのみに図形描画を制限（任意）

## 導入方法

### 1. VCC にリポジトリを登録（初回のみ）

以下のページを開き、「VCC に追加する」ボタンから QvShape の VPM リポジトリを VCC に登録します。

- https://yakigura.github.io/QvShape/

VCC が自動で起動しない場合は、VCC の `Settings > Packages > Add Repository` から以下の URL を直接登録してください。

```
https://yakigura.github.io/QvShape/index.json
```

### 2. パッケージの追加

VCC でプロジェクトを開き、`Manage Project` 画面から `QvShape`（`com.yakigura.qvshape`）を追加します。

### 3. 自動セットアップ

Unity 上部メニューから以下を実行します。

```
Tools > Yakigura > QvShape > Auto Setup All QvPen Sets
```

シーン内のすべての QvPen を自動検出し、拡張コンポーネント・UI・セッションが自動生成・配線されます。

（Hierarchy の `QvShape` オブジェクトを選択し、Inspector の `Auto Setup All QvPen Sets` ボタンからでも実行できます）

以上で導入は完了です。

### 導入を解除する場合

Hierarchy の `QvShape` オブジェクトを削除、または非アクティブにするだけで、QvPen 単体の状態に戻ります。QvPen 側には一切変更が入っていないため、元通りに動作します。

## 操作方法

基本操作は以下のとおりです。

### VR

| 操作 | 内容 |
|---|---|
| トリガーを引いてドラッグ | 描画 |
| 右スティックを**手前（下）**に 0.2 秒倒す | 手元メニューの開閉 |
| 【描画中】右スティックを**上**に 0.2 秒倒す | サブスタイル切替 |
| 【描画中以外】右スティックを**上**に素早く3回倒す | 鏡文字反転 |

### デスクトップ

| 操作 | 内容 |
|---|---|
| マウス左ドラッグ | 描画 |
| `M` キー | 手元メニューの開閉 |
| `Tab` キーを押しながら描画 | 視線平面上に作画 |
| `F` / `G` キー | サブスタイル切替 |
| `H` / `X` キー | 鏡文字反転 |

## カスタマイズ

Hierarchy の `QvShape` オブジェクト（`QvShape_Manager`）を選択すると、Inspector から各種設定を調整できます。

| 設定 | 内容 | 既定値 |
|---|---|---|
| 面・立体図形の最大半径 | 円・球体・塗りつぶし等の上限サイズ | 5.0 m |
| 直線の最大描画長 | 直線・直線点線の上限（測量線・ガイド用途を想定し長め） | 30.0 m |
| 他プレイヤー頭部保護半径 | この距離以内への描画をブロック | 0.3 m |
| スパム防止クールダウン | 描画確定後の待機時間 | 0.2 秒 |
| マスター限定モード | インスタンスマスターのみ図形描画を許可 | OFF |
| Enable Debug Log | 開発用ログ出力 | OFF |

> **注意**: これらの値は **Auto Setup 実行時に各 QvPen セットへ配布される初期値**です。変更を反映するには Auto Setup を再実行するか、各セットの `QvShape_SetExtension` 側で直接変更してください。

### キー割り当ての変更

他のアセットとキーが衝突する場合は、`QvShape_DrawingSession` および `QvShape_PenFollowMenu` の Inspector からデスクトップのキー割り当てを変更できます。

### 据え置き UI パネルの配置・削除

Auto Setup で生成される `UI_Panel` は通常の GameObject です。**設置後に位置やスケールを自由に変更できます。**

ワールドのレイアウトに合わないなど、パネルが不要な場合は**削除しても構いません。** 手元メニュー（VR: 右スティック手前 / デスクトップ: `M` キー）は引き続き動作します。

ただしデスクトップの利用者にとっては、マウスで直接クリックできる据え置きパネルの方が操作しやすい場面が多いため、可能であれば残しておくことをおすすめします。
